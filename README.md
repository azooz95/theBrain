# theBrain
let your office talk


## Main Technology 

- Python 3.12
- Milvus
- LangGraph
- Gemini API
- Google Workspace (Email, Calander)

## project structure

to install dependencies

```
pip install -e .
```

run the following code in the terminal for linux
```
export PYTHONPATH=$(pwd)
```
